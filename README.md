# خط‌خطی — بازی آنلاین نقاشی و حدس

بدون هیچ وابستگی خارجی (no npm dependencies) — فقط Node.js خام با یک پیاده‌سازی
دستی از WebSocket. یعنی هیچ‌وقت مرحله‌ی نصب پکیج در Render شکست نمی‌خورد.

## اجرای محلی

```
node server.js
```

سپس مرورگر را روی `http://localhost:3000` باز کن.

## دیپلوی روی Render

به پیام راهنمای مرحله‌به‌مرحله در چت مراجعه کن. خلاصه:

1. سه فایل `server.js`، `package.json` و پوشه‌ی `public/` (شامل `index.html`) را
   در یک ریپازیتوری روی گیت‌هاب آپلود کن.
2. در Render یک "Web Service" جدید بساز و همان ریپو را وصل کن.
3. Build Command: `npm install`
4. Start Command: `node server.js`
5. پلن Free را انتخاب کن و Deploy بزن.

## محدودیت‌های شناخته‌شده

- اگر کسی وسط بازی صفحه را رفرش کند، هویتش را از دست می‌دهد و باید دوباره با
  کد اتاق وارد شود (اگر بازی هنوز در لابی باشد).
- پلن رایگان Render بعد از ۱۵ دقیقه بی‌کاری می‌خوابد و اولین درخواست بعدی
  ممکن است ۳۰ تا ۵۰ ثانیه طول بکشد تا سرور بیدار شود.
